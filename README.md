# scripts de red

A lightweight collection of Linux network diagnostics, interface auditing, and environment validation utilities.

## Overview
This repository provides modular scripts designed for technical environments to automate interface verification, routing state validation, and network health checks across Linux distributions.

## Features
- Automated network interface discovery and status checks.
- Routing table verification and connectivity diagnosis.
- Minimal dependency overhead for lightweight execution.

## Prerequisites
- Linux (Debian, Ubuntu, Kali, Arch)
- Python 3.8+
- `iproute2` package

## Usage
```bash
python3 network_auditor.py
